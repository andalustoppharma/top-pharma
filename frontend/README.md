# Pharma System — Frontend

> الواجهة الأمامية لنظام إدارة شركة الأدوية (PWA).

## 📋 نظرة عامة

- **Framework:** React 18 + Vite
- **Language:** JavaScript ES2024 (بلا TypeScript)
- **State:** Context API + Axios (بلا Redux)
- **UI:** Tailwind CSS + مكونات مخصصة
- **PWA:** vite-plugin-pwa + Workbox
- **RTL:** عربي فقط

## 🚀 التشغيل السريع

```bash
# 1. تثبيت الاعتماديات
npm install

# 2. نسخ متغيرات البيئة
cp .env.example .env

# 3. تشغيل التطوير
npm run dev
# → http://localhost:5173
